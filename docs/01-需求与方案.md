# 01 — 需求与方案

> 状态：已确认（2026-10-01）。方案层面的变更须同步更新本文档，并在 `03-里程碑与进度.md` 记录。

## 1. 背景与目标

使用者希望自建一个闲鱼监控工具：为自己想买的商品（手动录入关键词）蹲守新上架好价，命中后第一时间通知自己。方案借鉴两个成熟开源项目：

| 维度 | ai-goofish-monitor | Xianyu-Supply-Monitor |
|---|---|---|
| 筛选逻辑 | AI 智能理解（分析图片/描述，自然语言创建任务） | 关键词规则匹配（必须包含/排除词） |
| 平台与部署 | 全平台，推荐 Docker，适合 NAS/服务器 7x24 | 仅 Windows 桌面软件（Electron） |
| AI 依赖 | AI 模式需配置 API Key；也支持纯关键词模式 | 完全无需 AI，纯本地规则 |
| 登录方式 | Chrome 扩展导出登录态 JSON 粘贴 | 内置浏览器窗口直接登录 |
| 核心优势 | 筛选质量高（排除配件当整机等垃圾信息）；多账号/代理轮换防封 | 上手极简；通知渠道丰富 |
| 主要局限 | 部署门槛稍高；AI 有成本 | 仅 Windows；纯关键词可能漏好货 |

**结论：自建新项目 xianyu-sniper，取两家之长，并补上「按关键词蹲目标价」这一两者都未突出做的场景。**

## 2. 已确认的需求决策

1. **运行环境**：本机（Windows）优先运行；架构上不做桌面壳绑定，预留服务器/Docker 迁移能力。
2. **筛选策略**：规则层 + AI 层双层筛选；AI 为可选项，可全局/按任务开关，关闭时纯规则直通。
3. **监控清单来源**：手动录入关键词与目标价（订单/收藏导入不在当前范围，仅作远期设想）。
4. **通知对象**：自己（Bark / Server 酱 / Telegram / 钉钉 / 通用 Webhook，按需配置）。

## 3. 从两个项目各取什么

**借鉴 ai-goofish-monitor（其真实技术栈：Python 异步 Playwright + asyncio、FastAPI Web、SQLite 主存储、OpenAI 兼容多模态 AI、Docker 部署、Chrome 扩展导出登录态）：**

- SQLite 单文件作为主存储（任务/商品/命中/日志）
- 登录态文件化（`state/` 目录），便于备份与服务器迁移
- Web 管理界面（任务管理、命中浏览、运行日志）
- 调度防封：随机抖动、账号/代理轮换（本项目作为预留接口）
- OpenAI 兼容接口接 AI，输出结构化判定

**借鉴 Xianyu-Supply-Monitor（工作区已有 Electron 实现，源码已留存至 `reference/`）：**

- 监听闲鱼搜索接口响应而非解析 DOM（抗改版，解析逻辑见 `reference/xianyu-supply-monitor/xianyu-parser.js`）
- 复用已登录会话的登录体验
- 规则筛选字段设计：最低/最高价、必须包含、排除词、地区包含/排除
- 多渠道通知实现（Bark/Server酱/Telegram/钉钉/息知/Webhook）

**本项目独有增强：**

- `target_price` 目标价蹲守：价格 ≤ 目标价才通知（蹲好价核心）
- AI 层可插拔旁路设计：规则层先行零成本过滤，AI 只处理漏网商品，成本可控

## 4. 技术选型结论

| 维度 | 推荐：Node.js 20+ | 备选 A：Python | 备选 B：Java 21 + Spring Boot |
|---|---|---|---|
| 浏览器采集 | Playwright（官方支持） | Playwright | Playwright for Java |
| 现成代码复用 | 可直接移植 `reference/` 解析与通知代码 | 可参考 ai-goofish-monitor 源码 | 无现成参考 |
| 本机 7x24 资源占用 | 低（~150MB） | 低 | 较高（JVM） |
| 迁移服务器 | 同一份代码 headless + Docker | 同左 | 同左 |
| 与使用者 Java 主栈契合度 | 中 | 中 | 高 |

**选定 Node.js 20+**。理由：`reference/` 中已验证的闲鱼接口解析与通知代码为 JS，直接移植消除最大试错成本；单语言轻量；迁移服务器仅换运行方式。若日后想换 Java 主栈，架构不变，替换为 Spring Boot + Playwright for Java + MyBatis-Plus 即可。

依赖清单：`playwright`、`better-sqlite3`、`fastify`、`@fastify/static`；通知/AI 使用 Node 内置 `fetch`，无额外 SDK。

## 5. 范围外（明确不做）

- 不做多用户/公网服务；Web UI 仅限本机或内网使用
- 不做自动下单、自动砍价等交易行为
- 不做高频抓取（间隔 <60s 的使用方式不被支持）
