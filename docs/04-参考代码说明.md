# 04 — 参考代码说明

> `reference/xianyu-supply-monitor/` 是对 **Xianyu-Supply-Monitor**（本工作区同级目录，**后续会被删除**）关键源码的只读留存快照。此目录仅作移植参考，禁止修改。

## 留存清单与移植指引

| 留存文件 | 原用途 | 移植到 | 说明 |
|---|---|---|---|
| `xianyu-parser.js` | 解析闲鱼搜索接口响应 JSON → 商品数组 | `src/parse/parser.js` | 核心资产。移植时做 ESM 化改造（原为 CommonJS/挂载方式见文件尾部），字段映射对齐 docs/02 数据模型 |
| `main.js` | Electron 主进程：内置浏览器窗口监听搜索接口、去重、规则筛选、多渠道通知实现 | 拆分移植 | ① 接口监听与请求匹配逻辑 → `src/capture/search.js`；② Bark/Server酱/Telegram/钉钉/息知/Webhook 的推送实现 → `src/notify/*` 各模块；③ 规则匹配的词分隔处理（逗号/中文逗号/竖线/换行）→ `src/filter/rule.js` |
| `monitor-preload.js` | 监控窗口 preload 注入脚本（配合接口监听） | `src/capture/` | Electron 特有，移植到 Playwright 时参考其拦截思路，用 `page.on('response')` 或 `context.route` 重新实现 |

## 与 Playwright 实现的差异提示

原项目基于 Electron（`session.webRequest` / 内置 BrowserView），本项目基于 Playwright：

| 原 Electron 机制 | Playwright 对应 |
|---|---|
| 内置窗口登录，会话自动保留 | 有头 `launchPersistentContext` 或 `storageState` 文件（docs/02 §4） |
| `webRequest.onCompleted` 监听响应 | `page.on('response', ...)` 过滤搜索接口 URL |
| 渲染进程注入 preload 收集数据 | 直接在 Node 侧读取 `response.json()` |
